# Política de licença

> **Decisão de produto:** o código próprio do Divino Bitcoin é distribuído sob **GPL-3.0-or-later**.

Esta escolha aplica copyleft forte ao aplicativo e aos scripts próprios distribuídos com ele. Quem redistribuir uma versão modificada deve preservar a licença, disponibilizar o código-fonte correspondente e manter avisos sobre alterações, nos termos da GPL. A licença não substitui auditoria de segurança nem transforma software experimental em uma carteira pronta para uso com valor econômico. [1] [2]

| Elemento | Regra adotada |
| --- | --- |
| Identificador SPDX | `GPL-3.0-or-later` |
| Código próprio | GPL-3.0-or-later |
| Dependências de terceiros | Mantêm as respectivas licenças e avisos |
| Distribuição de builds | Exige fonte correspondente, instruções de build e avisos de licença |
| Revisões de contribuição | Devem preservar a auditabilidade, os testes e a origem verificável das alterações |

O campo `private` do pacote impede publicação acidental no registro npm; não altera a licença do código. Para cumprir a diretriz de abertura na primeira distribuição pública, o repositório deverá estar publicamente acessível, conter o texto integral da licença, um inventário de dependências e instruções reproduzíveis de build. Esta é uma definição técnica de projeto, não aconselhamento jurídico; uma revisão jurídica independente continua necessária antes de qualquer lançamento público.
