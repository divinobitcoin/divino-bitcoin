# Divino Bitcoin Community Channels

## Official Telegram channel

The official Divino Bitcoin Telegram channel is [@divinobitcoin](https://t.me/divinobitcoin). It is a public space for community updates and general discussion about the project.

The channel does not change the project’s current technical scope. Divino Bitcoin remains in local demonstration mode, with Signet as the sole development environment. Mainnet, real funds, seeds, private keys, recovery, signing, broadcast, operational endpoints, and active Lightning remain blocked.

## Participation boundaries

The community welcomes respectful, evidence-based discussion, contributions, and review. Spam, fraud, harassment, token promotion, investment solicitation, fabricated claims, and pressure to bypass documented security gates are not accepted.

Never post or send seeds, private keys, recovery material, passwords, authentication codes, API keys, personal data, device backups, or other sensitive information in Telegram. Do not report security vulnerabilities through the channel. Follow [SECURITY.md](../SECURITY.md) for responsible security disclosure and use `contatodivinobitcoin@proton.me` for general contact.

## Official-channel scope

The Telegram channel is a communication link only. It does not provide wallet support, financial advice, custody services, payment handling, automated moderation, or an official bot. Treat any account, message, payment request, investment claim, or request for sensitive material that falls outside this statement as untrusted.
